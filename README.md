# MDM Ideation — Master Data Management for StartingBlocks

Planning artefacts for adding a partner-level Master Data Management capability to the StartingBlocks Admin App (SBAA). All decisions are closed as of 2026-10-06; this repo is the record.

| File | What it is | Read it if… |
|---|---|---|
| `ProjectScope.md` | 26 decisions with rationale, in/out of scope, risks, future scope | you need to know *why* |
| `ProjectPlan.md` | One-page staged plan | you need the shape of the work |
| `ImplementationPlan.md` | 76 engineering steps against the SBAA monorepo, with checks and release order | you are building it |
| `ProjectPlan.guide.html` | 15-slide walkthrough for a group — open in a browser, `→`/`←` to navigate, `P` to print | you are presenting it |
| `mockup/mdm-prototype.html` | Clickable UI mockup in SBAA's chrome; switch roles with "Acting as" | you want to see it |

Related repos: [`startingblocks_admin_app`](https://github.com/edanalytics/startingblocks_admin_app), [`sbaa_api_client`](https://github.com/edanalytics/sbaa_api_client).

The mockup and guide load IBM Plex Sans and Bootstrap Icons from CDNs; offline they fall back to system fonts and blank icons. `mockup/logo-sb.svg` is copied from `startingblocks_admin_app` (Apache 2.0).
